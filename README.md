## 🌐 English

### 📖 Overview

A comprehensive Python application designed for industrial quality control, specifically for extracting, analyzing, and visualizing flatness measurement data from PDF reports. The system provides both graphical (GUI) and command-line (CLI) interfaces, with advanced 3D visualization and automated report generation capabilities.

**📐 Compatible Equipment:**

- **Niigata Seiki Levelnic Series** - Precision flatness measurement systems
- Reads PDF reports generated by Levelnic measurement instruments
- Supports standard Niigata Seiki PDF format specifications

**Key Capabilities:**

- Automated PDF parsing and data extraction
- Real-time data preview and validation
- Interactive 3D surface visualization
- Template-based automated reporting
- Batch processing support
- Excel integration with custom formatting

### ✨ Key Features

#### 📥 Data Processing

- **Smart PDF Parsing**: Automatically extracts flatness measurement data from standardized PDF reports generated by **Niigata Seiki Levelnic** measurement systems
- **Equipment Compatibility**: Specifically designed for Levelnic series precision measurement instruments
- **Data Validation**: Built-in validation to ensure data integrity
- **Multi-format Export**: CSV, Excel (XLSX) with custom formatting
- **Batch Processing**: Process multiple PDF files simultaneously via CLI

#### 📊 Visualization & Analysis

- **Interactive 3D Graphs**: Real-time 3D surface plots showing flatness distribution

### 💻 Usage Guide

#### 🎨 GUI Mode (Recommended for Most Users)

**Launch Application:**

```bash
python -m app.gui
```

**Workflow:**

1. **Import PDF**
   - Click "Import PDF" button
   - Select flatness measurement PDF file
   - Data will be automatically parsed and displayed

2. **Review Data**
   - Check header information in the top panel
   - Verify measurement results in the data table
   - Scroll through all measurements

3. **Export Options**
   - **Export to Data CSV**: Save raw data to CSV files
   - **Export to Report CSV**: Generate formatted report using templates
4. **Visualization**
   - Click "Show Flatness" to view 3D surface plot
   - Rotate and zoom the graph interactively
   - Export graph as image if needed

5. **Template Management**
   - Click "Adjust layout" to open templates folder
   - Customize Excel templates as needed

#### ⌨️ CLI Mode (Batch Processing)

**Basic Command:**

```bash
python -m app.main_cli --pdf <path-to-pdf> --name <record-name> --out <output-directory>
```

**Examples:**

```bash
# Single file processing
python -m app.main_cli --pdf input_pdfs/sample.pdf --name "Record_001" --out output_data

# Batch processing with script
for %%f in (input_pdfs\*.pdf) do (
    python -m app.main_cli --pdf "%%f" --name "%%~nf" --out output_data
)
```

**Command-line Arguments:**

- `--pdf`: Path to input PDF file (required)
- `--name`: Record name for output files (required)
- `--out`: Output directory path (optional, default: ./output_data)

### 🐛 Troubleshooting

#### Common Issues

**❌ ModuleNotFoundError: No module named 'pdfplumber'**

```bash
# Solution: Install dependencies
pip install -r requirements.txt
```

**❌ PDF parsing returns empty data**

- **Cause**: PDF may be image-based or encrypted
- **Solution**: Ensure PDF contains selectable text, not scanned images

**❌ GUI doesn't launch**

- **Cause**: PySide6 not properly installed
- **Solution**:
  ```bash
  pip uninstall PySide6
  pip install PySide6
  ```

**❌ Template not found error**

- **Cause**: Missing or incorrect template path
- **Solution**: Check that `templates/` folder exists with required .xlsx files

**❌ Graph display issues**

- **Cause**: Plotly or matplotlib not installed
- **Solution**:
  ```bash
  pip install plotly matplotlib --upgrade
  ```

#### Performance Tips

1. **Large PDF Files**: For PDFs > 50 pages, use CLI mode for better performance
2. **Batch Processing**: Process files in groups of 10-20 for optimal memory usage
3. **Template Caching**: Keep template files in the default location for faster access

### 🐛 Khắc phục Sự cố

#### Vấn đề Thường gặp

**❌ ModuleNotFoundError: No module named 'pdfplumber'**

```bash
# Giải pháp: Cài đặt dependencies
pip install -r requirements.txt
```

**❌ Phân tích PDF trả về dữ liệu rỗng**

- **Nguyên nhân**: PDF có thể dựa trên hình ảnh hoặc được mã hóa
- **Giải pháp**: Đảm bảo PDF chứa text có thể chọn, không phải hình ảnh scan

**❌ GUI không khởi chạy**

- **Nguyên nhân**: PySide6 không được cài đặt đúng cách
- **Giải pháp**:
  ```bash
  pip uninstall PySide6
  pip install PySide6
  ```

**❌ Lỗi không tìm thấy template**

- **Nguyên nhân**: Thiếu hoặc đường dẫn template không đúng
- **Giải pháp**: Kiểm tra thư mục `templates/` tồn tại với các file .xlsx cần thiết

**❌ Vấn đề hiển thị biểu đồ**

- **Nguyên nhân**: Plotly hoặc matplotlib không được cài đặt
- **Giải pháp**:
  ```bash
  pip install plotly matplotlib --upgrade
  ```

#### Mẹo Hiệu suất

1. **File PDF Lớn**: Với PDF > 50 trang, sử dụng chế độ CLI cho hiệu suất tốt hơn
2. **Xử lý Hàng loạt**: Xử lý file theo nhóm 10-20 để sử dụng bộ nhớ tối ưu
3. **Template Caching**: Giữ file template ở vị trí mặc định để truy cập nhanh hơn
